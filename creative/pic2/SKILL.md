# pic2 — image2.5 中轴夹景海报提示词

把任意主题（歌名/概念/意象）改写为 image2.5「中轴夹景」文化展览海报提示词。2026-10-11 由用户验证：主题「至少还有你」→ 中轴夹景（衣袖+发丝+人脸+暖金）流程可用。

## 触发
- 用户给主题并要求「中轴夹景」海报 / museum poster / editorial design 风格
- 用户发来中轴夹景模板 + 主题，要求「按原格式重新输出一份」
- 注意：输出**只要提示词内容**；模板允许人物动作夹景（与 pic1 不同，pic1 禁止人物）

## 模板字段（必须全部保留，格式固定）

【主题】：<主题名>
【中文标题】：<主标题>
【英文标题】：<英文副题>
【左侧元素】：<左元素描述>
【右侧元素】：<右元素描述>
【中轴内容】：<中轴元素描述>
【夹景方式】：人物动作 / 光影投射 / 正负对照 / 烟雾气流 / 实体轮廓（单选或组合）
【主色调】：<色1>（背景）、<色2>（灯光/高光）
【辅助色】：<色1>（用途）、<色2>（用途）、<色3>（用途）
【日期 / 场馆】：<日期> · <场馆>
【画面比例】：9:16

## 正文描述结构（保留原模板口吻，主题相关化）

生成一张具有强设计感和文化展览气质的「中轴夹景」海报。
- 第一段：画面建立垂直中轴，左右元素推向中央；说明左右元素如何共同表达主题（不是对称装饰，是同一主题的不同状态）
- 夹景方式段：按所选方式描述具体实现（人物动作=姿态/衣袖/布料/身体曲线夹负形；光影投射=两侧阴影亮面收束；正负对照=原版与成品/实体与印痕/反刻与正印；烟雾气流=两股连续线条围绕中央；实体轮廓=器物/建筑/自然形态边缘围出中心）
- 标题段：标题必须参与构图，可用大字纵排/横排/错位/上下拆分/跨区排版，**不要每次都套用四字标题格式**；允许与主体轻微穿插遮挡但保持清晰可读
- 信息密度段：中轴/边栏/底部加展览信息 + 小型研究模块（动作轨迹/工艺步骤/气流变化/结构示意），像 museum poster 和 editorial design
- 色彩段：3–5 个主要颜色，明确大色块关系；第一眼看左右力量与中轴聚焦，第二眼读标题，第三眼发现构图与主题联系
- 整体要求段：高级、清晰、完整、层次丰富、视觉冲击，避免机械对称、固定模板感、PPT 式信息框、无意义装饰、斑驳噪点、文字模糊、低完成度 AI 感

## 出图（完整流程最后一步）
提示词生成后直接调默认文生图工具出图（RunningHub，见 runhub-image-gen 技能）：
```bash
python3 ~/tools/runhub/runhub_img.py t2i "$(cat prompt.txt)" --app 2098218128315609089 --out 输出.png
```
- **默认生图应用固定为 image2.5 sunburst (2098218128315609089)**：https://www.runninghub.cn/ai-detail/2098218128315609089（用户 2026-10-11 指定默认，~0.036元/张，不支持 ratio/res，输出约 3:4）
- 长中文提示词写入文件再 $(cat) 传入，避免 shell 转义；t2i 前把 markdown 符号（**、- 列表、【】）清理为纯文本更稳
- 2026-10-11 实测：主题「至少还有你」中轴夹景 → 生成成功

## 固定标注（所有输出必须带）
每次生成提示词，在提示词末尾（或合适位置）补充一句：**右上角粗体字标注：FAFO工作室**（2026-10-11 用户指定，pic1-5 全部适用）。

## 经验
- 中轴夹景的精髓：左右不是对称装饰，而是同一主题的两种状态（例：承接的手 vs 飘散的发 = 相依）；选夹景方式先想主题的二元对立/互补
- 标题参与构图：中轴纵排 + 每字偏移 1-2 度可制造不稳定感（情感主题适用）；英文副题横排小字放标题下方
- 研究模块是 museum poster 感的关键：加三帧动作轨迹线稿/工艺步骤示意，信息密度立马上来
- pic1=通用主题海报（禁止人物）；pic2=中轴夹景海报（允许人物动作夹景），触发时区分
