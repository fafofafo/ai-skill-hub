# picbpskyfo — 史诗佛教巨佛海报提示词（picbpnew 骨架版）

2026-10-23 创建：**生成方式参考 picbpnew**（主题嵌入开头 → 画面内容全部由主题派生 → 画质/色调/风格三段收束 → 左上角超大主标题/底部系列署名/右上 FAFO），内容保留 picskyfo 的史诗佛教神话 CGI 画风（巨佛占 80% 上半身出画/古鎏金铜/圆形 mandorla/佛光/云海石台/ONE 微缩僧人持 ONE 法器/24mm 低角/PBR）。

## 触发
- 用户给主题/造像概念并要求「佛教」「巨佛」「史诗神话」「超写实 CGI」「造像」风格的海报版
- 用户要求「按 picbpskyfo 出图」——按主题自动派生造像与场景内容
- 注意：输出**只要提示词内容**；模板为中文；主题嵌入开头 + 左上主标题

## 骨架标准（2026-10-22 用户定，picbp 前缀四要素缺一即不合格）
1. 主题嵌入开头（「请生成一张以「<主题>」为主题…」）
2. 画面左上角超大主标题（bold 立体挤压感 + 利落描边 + 清晰投影 + 第一视觉焦点 + 不能写错字）
3. 底部或角落小号「AIXZD ZHAPU PROJECT SERIES」系列署名
4. 末尾补「右上角粗体字标注：FAFO工作室」

## 派生规则（picbpnew 方式：主题决定内容）
- **主题决定一切画面内容**：佛尊身份、莲座材质、手印法器、表面质感、背光纹样与镶嵌、台基环境、僧人形象与法器、刻字位置，全部按主题气质派生
  - 例「FAFO工作室」→ 毗卢遮那佛+青瓷莲座+工作室纹样背光、石壁刻「FAFO工作室」、僧人执画稿与锡杖
  - 例「长安」→ 唐代释迦牟尼+黑石须弥座+卷草纹背光、汉白玉阶、执香炉的唐代僧人
  - 例「倩女幽魂」→ 幽蓝夜色观音+青石贴金+飞天纹背光、赤色岩窟、执灯信女
- **画风三段固定**：画质=超写实电影级 CGI（PBR/真实金属石材纹理/衣褶体积/雾气光柱）；色调=主色随主题 + 澄澈蓝宝石天空 + 暖阳 + 冷蓝绿阴影；风格=庄严神圣/空寂辽远/史诗宗教尺度/肃穆不可亵渎
- **构图比例固定**：巨佛约 80% 且上半身出画 / ONE 微缩人物持 ONE 法器 / 24mm 低角仰拍 / 云海石台 / 无多余人物
- **材质红线**：深色古鎏金铜（岁月金高光+暖铜阴影）——**禁塑料金、禁大理石**、禁动漫感
- **标题（picbpnew 骨架）**：左上角超大主标题=主题，bold 立体石刻艺术字+描边+投影，第一视觉焦点，不能写错字
