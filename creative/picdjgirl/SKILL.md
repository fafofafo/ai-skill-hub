# picdjgirl — 夜店DJ美女数字插画海报（主题派生式）

2026-10-26 创建：`picgirlsunny3` 的**美女向主题派生版**：1 个年轻美女主体 + 与主题相关的背景，画风固定继承 picgirlsunny3（数字插画 3D 渲染 / 高调明亮 / 冷暖平衡 / 文字三件套），固定造型从「橙框墨镜+撞色衬衫+蓝天」换成「夜店DJ扮相体系 + 夜店现场场景」。

## 触发
- 用户要求「picdjgirl」「夜店DJ」「DJ美女」「夜店风」
- 主题要「夜店 / DJ / 电音 / 潮流派对」的美女海报
- 注意：输出**只要提示词内容**；**扮相与场景都随主题派生**，画风要素固定

## 画风定义（继承 picgirlsunny3，勿改）
| 要素 | 内容 |
|---|---|
| 画种 | 风格化数字插画、3D 渲染质感（不是照片不是真人摄影、不是 2D 平涂）|
| 固定造型 | 夜店DJ扮相体系：时尚 DJ 墨镜（炫彩镜片，可随主题微调）、DJ 耳机挂颈或单耳、亮片/霓虹/潮流印花服饰、涂鸦风配饰 |
| 基准发型 | 由主题派生的 DJ 发型（银灰短发/脏辫/彩色挑染，发丝根根分明）|
| 背景 | **由主题派生的夜店现场场景**（DJ台/霓虹灯/激光光束/人群剪影/舞池）：霓虹光效、明净通透、轻度虚化但保留场景元素边缘清晰 |
| 光 | 高调明亮（夜店霓虹光效/激光束）、明亮轻盈、大面积柔和高光、阴影浅而通透、清爽边缘光 |
| 色彩 | 冷暖平衡：人物亮色撞色（荧光绿/紫/粉/橙）+ 背景霓虹紫蓝粉，明快鲜艳不过艳 |
| 构图 | 紧凑半身肖像、人物居中偏下、夜店场景背景占上部与两侧 |

### 派生规则
- **必须主题派生**：**扮相（发型/墨镜镜片/服饰/配饰/主题相关细节）与场景（夜店现场 + 主题相关布置）同时随主题派生**、手持物、环境色
- **必须固定**：夜店DJ扮相体系（DJ墨镜+耳机）、夜店现场、高调明亮、数字插画画风、3:4、文字三件套
- **禁止**：照片写实、2D 平涂、阴郁暗调、高饱和荧光、多余英文标语
