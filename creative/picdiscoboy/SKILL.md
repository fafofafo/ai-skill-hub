# picdiscoboy — 80年代disco男数字插画海报（主题派生式）

2026-10-26 创建：`picgirlsunny3` 的**男性向主题派生版**：1 个中年男性主体 + 与主题相关的背景，画风固定继承 picgirlsunny3（数字插画 3D 渲染 / 高调明亮 / 冷暖平衡 / 文字三件套），固定造型从「橙框墨镜+撞色衬衫+蓝天」换成「80年代时尚扮相体系（蛤蟆镜+喇叭裤） + 80年代夜店disco现场」。

## 触发
- 用户要求「picdiscoboy」「80年代」「disco」「蛤蟆镜」「喇叭裤」
- 主题要「复古迪斯科 / 80年代 / 迪斯科舞厅」的男性海报
- 注意：输出**只要提示词内容**；**扮相与场景都随主题派生**，画风要素固定

## 画风定义（继承 picgirlsunny3，勿改）
| 要素 | 内容 |
|---|---|
| 画种 | 风格化数字插画、3D 渲染质感（不是照片不是真人摄影、不是 2D 平涂）|
| 固定造型 | 80年代时尚扮相体系：蛤蟆镜（大框复古墨镜，镜面反光霓虹）、花衬衫/亮片衬衫、喇叭裤、金链子/复古配饰 |
| 基准发型 | 由主题派生的80年代发型（大背头/卷发/中分，发丝根根分明）|
| 背景 | **由主题派生的80年代夜店disco现场场景**（迪斯科球/霓虹灯/舞池/复古灯光/人群剪影）：霓虹光效、明净通透、轻度虚化但保留场景元素边缘清晰 |
| 光 | 高调明亮（disco霓虹光效/迪斯科球反射光）、明亮轻盈、大面积柔和高光、阴影浅而通透、清爽边缘光 |
| 色彩 | 冷暖平衡：人物亮色撞色（金/红/紫/蓝）+ 背景disco霓虹，明快鲜艳不过艳 |
| 构图 | 紧凑半身肖像、人物居中偏下、disco场景背景占上部与两侧 |

- **必须主题派生**：**扮相（发型/服饰/配饰/主题相关细节）与场景（80年代disco现场 + 主题相关布置）同时随主题派生**、手持物、环境色
