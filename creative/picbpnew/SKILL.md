# picbpnew — 现代波普艺术拼贴海报提示词

把任意主题（城市/街区/团体名）改写为「现代波普艺术拼贴」海报提示词（image2.5 风格）。2026-10-14 由用户基于 picbp 创建：**去掉所有复古成分**，保留结构/流程/署名。

## 触发
- 用户给主题并要求「现代波普」「Pop Art Collage」「拼贴插画」「现代海报」风格
- 用户发来完整模板 + 主题，要求「按原格式重新输出一份」
- 注意：输出**只要提示词内容**；模板为中文，保留全部细节约束（尺寸/风格/建筑/巨型元素/配色/署名）
- 与 picbp 区别：picbp 复古（美式漫画/半色调网点/套印错位/复古印刷颗粒），本技能全现代（高清渐变/干净描边/现代插画/极简纹理）

## 骨架标准（2026-10-22 用户定，所有 picbp 前缀技能共用）
本技能的模板结构是 **picbpX 命名族的骨架标准**，四要素缺一即不合格：
1. 主题嵌入开头（「请生成一张以「<主题>」为主题…」）
2. 画面左上角超大主标题（bold 立体挤压感艺术字 + 利落描边 + 清晰投影 + 第一视觉焦点 + 不能写错字）
3. 底部或角落小号「AIXZD ZHAPU PROJECT SERIES」系列署名
4. 末尾补「右上角粗体字标注：FAFO工作室」

用户明确规则：**不以本骨架生成的独立模板，不得使用 picbp 前缀**。把某个独立模板转成 picbp 版时=新建平行技能（原技能保留），只换骨架、画风/器物/禁令内容原样保留；不再需要的独立模板按用户指令删除（删后清理各技能族清单引用）。

**内容层第五要求：主题必须驱动画面实体**（用户说「XX 要参考 picbpnew 的方式构图和生成内容」即指此）。四要素只是排版骨架——固定场景型模板转骨架时若无条件照抄原场景、只把主题写进标题和匾额，等于没对齐。把场景对象参数化成 `<由主题派生的屋顶形制>`/`<由主题派生的材质色彩>`/`<由主题派生的装饰构件>`/`<由主题派生的主角或点景人物>` 并给派生示例。三档分清：**必须主题派生**=建筑形制/材质色彩/装饰纹样/构件/主角身份/主题道具；**必须固定**=画风三段（画质/色调/风格）与原模板写明的构图比例参数（如「主体占画面大部分/点景人物 0.5%/100mm 长焦/唯一现象/无次要建筑」）——后者是模板灵魂，随主题改会毁掉类型识别。

请生成一张以「<地点>·<主题>」为主题的现代波普艺术拼贴海报，3:4 竖版构图，尺寸 1086×1448，8K UHD，full-bleed，no outer border，background to canvas edge。整体风格采用 Maximalist Pop Art Collage，融合现代插画、街头艺术、平面设计与拼贴插画。画面使用干净利落的手绘轮廓、鲜明撞色色块、高饱和渐变色与细腻纸张颗粒，形成热闹、密集、夸张、有趣的城市文化插画。整体为平面插画质感，不要摄影写实，不要3D玩具风。画面左上角放置超大主标题「<主标题>」，字体为 bold、立体挤压感、现代波普艺术字，带利落描边和清晰投影，醒目且准确，不能写错字。标题是第一视觉焦点，具有很强设计感。画面右上区域表现<地点>老城与<地域>风情建筑，包含<建筑细节清单>等具有<地域>特色的建筑细节，建筑紧凑排列，层层叠叠，形成密集的老街氛围。画面中部加入具有<地点>城市气息的街头元素，如现代招牌、<地域>店铺标识、骑楼下店铺、木质招牌、<地域>窗花、当代路牌，以及具有地方感的交通与生活元素，增强街巷故事感。画面底部前景放大 2 到 3 个代表<地点>文化的巨型元素，例如<本地特产/文化元素清单>。物体比例夸张，可以像建筑一样大，从左右底角延伸进画面，与街区建筑形成超现实拼贴关系。整体色彩以亮黄、珊瑚橙、朱红、米白、青绿色为主，形成鲜明对比，避免整张画面被单一颜色覆盖。构图饱满但层次清晰，元素前后穿插，几乎没有无意义空白，但主标题必须清晰可读，地标建筑必须明确可辨。画面底部或角落以不抢眼的方式加入小号品牌文字「AIXZD ZHAPU PROJECT SERIES」，作为系列署名，排版精致克制，不影响主体视觉。最终输出为一张完整的历史街区商业插画海报，现代漫画感强，视觉张力足，极繁但有秩序，具有旅游海报与文创海报的高级设计感。

## 经验
- 现代拼贴精髓：干净轮廓+高饱和撞色+渐变+细腻颗粒；左上超大立体艺术字标题；底部 2-3 个巨型元素像建筑一样大
- **与 picbp 的复古差异（改这 5 处即可互转）**：
  1. 风格：复古美式漫画/经典旅行海报 → 现代插画/街头艺术/平面设计
  2. 纹理：复古半色调网点/套印错位 → 高饱和渐变/细腻纸张颗粒
  3. 描边：粗黑手绘轮廓 → 干净利落的手绘轮廓
  4. 标题：复古波普艺术字/厚重阴影 → 现代波普艺术字/清晰投影
  5. 街头元素：老式招牌/复古路牌 → 现代招牌/当代路牌
- 配色（亮黄/珊瑚橙/朱红/米白/青绿）与署名（AIXZD ZHAPU PROJECT SERIES）为固定模板，不随主题变
- pic 技能族：pic1-7 + picbp（复古波普）+ picbpnew（现代波普）；触发时按模板区分
