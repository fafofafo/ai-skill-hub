# picbook3d — 旅行艺术插画·3D纸雕立体书（给定城市主题，4:5竖版）

2026-10-27 创建：全新旅行插画技能，五元素基准与 pichotpoolfull 完全一致（42-55%/+15~+55/55-65%/0.10-0.22/10-20%），未下调。**画风固定：精致水彩+细线墨绘+手工3D纸雕立体书工艺，打开的书幻化为微型城市**。v3为定稿版本。

## 触发
- 用户要求「picbook3d」「旅行插画」「立体书城市」「4:5竖版插画」
- 用户给出城市主题（如「印度海得拉巴」「巴黎」「东京」等）
- 注意：输出**只要提示词内容**；**主题（城市）决定地标与场景元素**，画风要素固定

## 定稿提示词模板（v3版本，直接使用）

```
创作一幅高品质的4:5竖版Instagram旅行艺术插画，以{城市名}为题材，完全由文本生成，不使用任何参考图片。

风格：精致水彩与细线墨绘相结合，辅以手工打造的3D纸雕/立体书工艺。一本古旧的打开的书幻化为一座立体的微型城市。画面梦幻、优雅、怀旧且充满向往，呈现顶级旅行类编辑品质。清晰的墨线勾勒建筑轮廓，水彩填色均匀明亮饱满，高饱和色彩鲜艳，阴影浅而通透，明亮自然的高调光线，富有氛围感的纵深。绝不写实、卡通化或平面化。

镜头与书籍：略带仰角的四分之三视角，俯拍角度约25–30°。打开的书占据画面下部约30%，书脊位于画面偏下中央，书页呈浅浅的V形折叠。展现真实的书页厚度与层次分明的边缘，纸张边缘清晰锐利。整组作品保持统一的拍摄角度、书籍比例、透视与构图方向，避免俯视或极端变形。

城市构图：城市从书页中自然生长而出。在画面中央突出呈现{城市名}标志性英雄级地标（如{具体地标名称}），并以3–5处可辨识的辅助地标作为背景衬托。必要时融入{城市名}当地的真实河流、滨水区、海岸线、湖泊、山峦、广场或风景元素。

前景添加一条微型步道或公园，点缀微小行人、地道交通工具、路灯、树木、花卉以及细腻的地方特色细节。所有建筑均保持直立姿态，结构严谨准确，边缘清晰锐利。

色彩与光线：整体色调高调明亮，明亮自然的高调光线（午后阳光感），大面积柔和高光，阴影浅而通透，建筑轮廓有清爽的边缘光。高饱和色彩，饱和度42-55%，色温偏暖R-B+15~+55，明度55-65%，柔度控制在0.10-0.22，边缘清晰度10-20%。画面呈现梦幻、优雅、怀旧且充满向往的氛围，色彩明亮鲜艳、干净通透、不刺眼。
```

### 派生规则
- **必须主题派生**：城市名、地标、辅助地标、河流/湖泊/山峦等自然元素、地方特色细节
- **必须固定**：3D纸雕立体书工艺、水彩细线墨绘、4:5竖版、高调明亮、梦幻优雅怀旧氛围、五元素基准
- **禁止**：照片写实、2D平涂、阴郁暗调、高饱和荧光、俯视、极端变形

## 出图（默认工具）
**默认生图工具 = 全能图片 G_image2.5 sunburst**（app `2098218128315609089`，~0.036 元/张，输出约 880×1100≈4:5）：
```bash
python3 ~/tools/runhub/runhub_img.py t2i "$(cat prompt.txt)" --app 2098218128315609089 --out 输出.png
```

## 经验与迭代
- **FAFO工作室 v3 定稿**：S43.0%/R-B+47.5/明度54.3%/柔度0.236/边缘22.65%
- **宁德老登测试 v1**：S33.1%❌/R-B+26.8✅/明度58.9%✅/柔度0.222❌/边缘20.47%❌
  - 根因：S结构性偏低，需额外饱和词；柔度/边缘需加"柔和""不锐利"对冲
- **关键规则**：
  - **禁用**："柔和的水彩晕染""微妙阴影"（拉低S/推高柔度）
  - **必加**："高饱和色彩鲜艳""高调光线"（提S/明度）
  - **控柔度/边缘**：加"边缘柔和自然""不过分锐利"（防超上限）
- **S提色口诀**：翠绿元素大面积 + "饱和度拉满" + "色彩浓郁饱满"
