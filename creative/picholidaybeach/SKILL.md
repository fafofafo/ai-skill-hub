# picholidaybeach — 假日海滩·日光浴美女数字插画海报（主题派生式）

2026-10-27 创建：`picsearoad` 的**假日海滩版派生**：1 个日本 1980 年代昭和时期年轻美女（晒日光浴）+ 假日干净海滩场景，画风固定继承 picsearoad/picgirlsunny3（数字插画 3D 渲染 / 高调明亮 / 冷暖平衡 / 文字三件套），固定造型从「citypop 泳装+驾驶敞篷车在海岸线公路」换成「昭和 80 年代泳装+躺在海滩晒日光浴」，表情固定「开心惬意」。

## 触发
- 用户要求「picholidaybeach」「假日海滩」「日光浴」「沙滩美女」
- 主题要「假日 / 海滩 / 日光浴 / 度假」的美女海报
- 注意：输出**只要提示词内容**；**扮相与场景都随主题派生**，画风要素固定

## 画风定义（继承 picsearoad/picgirlsunny3，勿改）
| 要素 | 内容 |
|---|---|
| 画种 | 风格化数字插画、3D 渲染质感（不是照片不是真人摄影、不是 2D 平涂）|
| 固定造型 | **日本 1980 年代昭和泳装扮相体系**：复古泳装（连体泳装/复古分体泳装）+ 复古墨镜 + 草帽/遮阳帽/丝巾，日光浴姿态（躺在沙滩/沙滩椅/沙滩巾上）|
| 基准发型 | 由主题派生的昭和发型（大波浪卷发/马尾/盘发，发丝根根分明）|
| 表情 | **固定：开心惬意**（笑容放松、眼神明亮、享受日光浴的幸福惬意）|
| 背景 | **由主题派生的假日干净海滩场景**（白净沙滩/海浪/海水/遮阳伞/棕榈树/蓝天白云）：明净通透、轻度虚化但保留场景元素边缘清晰 |
| 光 | 高调明亮（假日阳光）、明亮轻盈、大面积柔和高光、阴影浅而通透、清爽边缘光 |
| 色彩 | 冷暖平衡：人物泳装亮色（红/黄/蓝撞色）+ 背景海蓝沙滩金，明快鲜艳不过艳 |
| 构图 | 紧凑半身/中景肖像（日光浴视角）、人物居中偏下、假日海滩场景背景占上部与两侧 |

### 派生规则
- **必须主题派生**：**扮相（发型/泳装/配饰/日光浴姿态/手势）与场景（假日海滩 + 主题相关布置）同时随主题派生**
- **必须固定**：日本 1980 年代昭和泳装扮相体系、**开心惬意表情**、假日干净海滩、高调明亮、数字插画画风、3:4、文字三件套
- **禁止**：照片写实、2D 平涂、阴郁暗调、高饱和荧光、多余英文标语

## 内容安全审查提示（继承 picsearoad）
- **泳装可能触发 image2.5 内容安全审查**（errorCode 1501「内容安全审查未通过」）：被拦截时**不要反复重试或尝试绕过**
- 应对：改为非泳装表述（如「夏日度假时装」「露肩连体裙装+薄纱罩衫」）能通过审核但结果可能不像泳装；或如实告知用户被平台拦截、建议换造型（用户拍板后再继续）
