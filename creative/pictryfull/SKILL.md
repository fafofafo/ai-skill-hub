## 五元素基准与验收（继承母版 v1.2.0，对齐 mvglassout/picglassout 实测）
目标=picglassout 实测基准（Loish 中调：S35.9/R-B+17.4/明度45.5/柔度0.137/边缘11.75），验收以贴近此基准为准（±3 内），画风表达可妥协。
| 元素 | 目标（picglassout 实测）| 实测（测试主题：FAFO工作室）|
|---|---|---|
| 饱和度 | ≈35.9%（±3）| v1: 30.9% / v2: **34.9 ✅接近** |
| R-B | ≈+17.4（±3）| v1: +7.1 / v2: **+16.9 ✅完全对齐** |
| 明度 | ≈45.5%（±3）| v1: 48.4% / v2: **48.1 ✅接近** |
| 柔度 | ≈0.137（±0.03）| v1: 0.223 / v2: **0.191**（差0.05，画风差异） |
| 边缘 >40 | ≈11.75%（±3）| v1: 18.32% / v2: **15.58**（差3.8，画风差异） |

**验收**：出图后跑 `python3 ~/.hermes/scripts/img_metrics.py <图>`，五项尽量贴近 picglassout 实测基准（±3 内）；文字另用 VL 逐字复核。
