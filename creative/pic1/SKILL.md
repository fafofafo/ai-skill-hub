# pic1 — image2.5 主题海报提示词改写

把任意主题（歌名/概念/意象）改写为 image2.5 可用的中文海报提示词。2026-10-11 由用户验证：主题「至少还有你」→「睫毛上的心跳」流程一致可用。

## 触发
- 用户给一个主题（常为歌名），要求输出海报/生成图提示词
- 用户说「测试一下，主题：XXX+技能pic1」
- 注意：输出**只要提示词内容**，不要其他解释；提示词中**不要出现人物**（可留手部/局部特写，禁止人脸、完整人物、剪影、双人相拥轮廓）

## 硬性规则（必须遵守）
1. 9:16 竖版构图
2. 文字用**中文简体**（可保留副题/印章小字，均为简体中文）
3. 画面中出现的关键文字仅限主题相关词，不得自行添加虚构标题/品牌/标语
4. 禁止：人物（人脸/完整人物/侧脸剪影/双人轮廓）、双重曝光人像、封闭人物轮廓、满版拥挤、硬边矩形照片、九宫格拼贴、景物穿模、器物变形、城市地标混用、民族服装混用、多指断指手部畸形、错别字、乱码、多余文字、廉价宣传单质感、霓虹色、塑料感3D、水印、品牌Logo、无关标识（如 AIXZD ZHAPU PROJECT SERIES）
5. 格式固定（见模板），段落标题不可省略

## 出图（完整流程最后一步）
提示词生成后可**直接调默认文生图工具出图**（RunningHub，见 runhub-image-gen 技能）：
```bash
python3 ~/tools/runhub/runhub_img.py t2i "$(cat prompt.txt)" --ratio 9:16 --res 2k --out 输出.png
```
- **默认生图应用固定为 image2.5 sunburst (2098218128315609089)**：https://www.runninghub.cn/ai-detail/2098218128315609089（用户 2026-10-11 指定默认，~0.036元/张，不支持 ratio/res，输出约 3:4）
- 长中文提示词写入文件再 $(cat) 传入，避免 shell 转义；t2i 前把 markdown 符号（**、- 列表、【】）清理为纯文本更稳
- 2026-10-11 实测：主题「睫毛上的心跳」→ prompt(1921字) → t2i 生成成功

## 经验
- 主题=歌名时：先抓歌的情感内核（深情/遗憾/炽热/轻盈），意象围绕内核发挥，不必忠实歌词细节
- 无人物要求与「情感温度」不冲突：用手部特写、旧物、光影、花、尘、信纸等传递情绪
- 2026-10-11 实测：主题「至少还有你」→ 时光/旧物/相依意象；主题「睫毛上的心跳」→ 轻盈/贴近/微颤意象，流程通用
