# picrainnight — 居家雨夜女数字插画海报（主题派生式）

2026-10-26 创建：`picgirlsunny3` 的**美女向主题派生版（室内版）**：1 个年轻美女主体 + 与主题相关的背景，画风固定继承 picgirlsunny3（数字插画 3D 渲染 / 高调明亮 / 冷暖平衡 / 文字三件套），固定造型从「橙框墨镜+撞色衬衫+蓝天」换成「居家休闲装扮相体系 + 家里室内雨夜窗景」。

## 触发
- 用户要求「picrainnight」「居家」「雨夜」「窗外雨夜」「室内休闲」
- 主题要「居家 / 雨夜 / 窗边 / 温暖室内」的美女海报
- 注意：输出**只要提示词内容**；**扮相与场景都随主题派生**，画风要素固定

## 画风定义（继承 picgirlsunny3，勿改）
| 要素 | 内容 |
|---|---|
| 画种 | 风格化数字插画、3D 渲染质感（不是照片不是真人摄影、不是 2D 平涂）|
| 固定造型 | 居家休闲装扮相体系：卫衣/毛衣/宽松T恤/睡裙、拖鞋、舒适居家感、发丝自然披散 |
| 基准发型 | 由主题派生的居家发型（披肩发/丸子头/马尾，发丝根根分明）|
| 背景 | **由主题派生的家里室内雨夜场景**（客厅/卧室/沙发/窗边/窗外雨夜城市灯火）：室内暖光、窗外雨丝霓虹、明净通透、轻度虚化但保留场景元素边缘清晰 |
| 光 | 高调明亮（室内暖光+窗外雨夜冷光）、明亮轻盈、大面积柔和高光、阴影浅而通透、清爽边缘光 |
| 色彩 | 冷暖平衡：人物居家色（米白/暖粉/淡蓝/奶黄）+ 背景室内暖光与窗外雨夜冷蓝，明快鲜艳不过艳 |
| 构图 | 紧凑半身肖像、人物居中偏下、室内雨夜场景背景占上部与两侧 |

## 模板结构（主题派生式，3:4）

风格化数字插画肖像，3D渲染质感的潮流人物海报，不是照片不是真人摄影。主题「<主题>」：画面主体为 1 个年轻美女的半身特写，留着<由主题派生的居家发型：披肩发/丸子头/马尾等>，发丝根根分明细节清晰，穿着<由主题派生的居家休闲装：宽松卫衣/毛衣/睡裙等>，<由主题派生的居家细节：抱着抱枕/捧着热饮/披着毯子/光脚穿拖鞋>，一只手<由主题派生的动作：托腮望向窗外/握着马克杯/翻书/抱膝>，嘴角微扬温柔松弛。人物五官为风格化数字绘制（简洁明快的插画式造型，皮肤带柔和磨砂高光质感），神情温柔恬静、惬意放松。背景为<由主题派生的家里室内雨夜场景：客厅/卧室/沙发/窗边/窗外雨夜城市灯火>，<由主题派生的室内与雨夜元素：暖黄台灯/绿植/书架/窗玻璃雨珠/窗外霓虹雨丝/主题相关元素>，明净通透、光线充足；背景轻度虚化但保留场景元素边缘清晰可见，人物与背景之间有柔和光斑过渡。整体色调冷暖平衡：人物身上是居家色（米白/暖粉/淡蓝/奶黄），背景以室内暖光与窗外雨夜冷蓝为主，与人物形成明快对比，色彩明亮鲜艳、饱和度中等偏上、干净通透、不刺眼不荧光不过艳。光线为明亮通透的高调光（室内暖光+窗外雨夜冷光），高调曝光、整体明亮轻盈，柔和的大面积高光，阴影浅而通透，人物轮廓有清爽的边缘光。人物面部、发丝、居家服饰衣纹、抱枕与配饰都保持清晰锐利的边缘细节。构图为紧凑半身肖像，人物居中偏下，室内雨夜场景背景占画面上部与两侧。画面左上角放置超大主标题「<主题>」，字体为 bold、立体挤压感、现代波普艺术字，带利落描边和清晰投影，醒目且准确，不能写错字，标题是第一视觉焦点。画面最底部中央区域以不抢眼的方式加入小号品牌文字「AIXZD ZHAPU PROJECT SERIES」，作为系列署名，完整清晰不被遮挡，排版精致克制，不影响主体视觉。右上角用粗体简体中文标注：FAFO工作室。除上述文字外不要生成任何其他英文文字或标语。

### 派生规则
- **必须主题派生**：**扮相（发型/居家服饰/居家细节/主题相关细节）与场景（家里室内雨夜 + 主题相关布置）同时随主题派生**、动作手持物、环境色
- **必须固定**：居家休闲装扮相体系、室内雨夜场景、高调明亮、数字插画画风、3:4、文字三件套
- **禁止**：照片写实、2D 平涂、阴郁暗调、高饱和荧光、多余英文标语
