# picbp — 复古波普艺术拼贴海报提示词（BP = Boom Pop）

把任意主题（城市/街区/团体名）改写为「复古波普艺术拼贴」海报提示词（image2.5 风格）。2026-10-11 由用户验证：主题「宁德老登团」→ 闽东老街+巨型特产拼贴流程可用。

## 触发
- 用户给主题并要求「复古波普」「Pop Art Collage」「拼贴插画」「旅行海报」风格
- 用户发来完整模板 + 主题，要求「按原格式重新输出一份」
- 注意：输出**只要提示词内容**；模板为中文，保留全部细节约束（尺寸/风格/建筑/巨型元素/配色/署名）

## 模板结构（中文，保留原句法）

请生成一张以「<地点>·<主题>」为主题的复古波普艺术拼贴海报，3:4 竖版构图，尺寸 1086×1448，8K UHD，full-bleed，no outer border，background to canvas edge。整体风格采用 Maximalist Pop Art Collage，融合复古美式漫画、经典旅行海报、丝网印刷质感与街头拼贴插画。画面使用粗黑手绘轮廓、鲜明撞色色块、复古半色调网点、纸张颗粒与轻微套印错位效果，形成热闹、密集、夸张、有趣的城市文化插画。整体为平面插画质感，不要摄影写实，不要3D玩具风。画面左上角放置超大主标题「<主标题>」，字体为 bold、3D 挤压感、复古波普艺术字，带粗黑描边和厚重阴影，醒目且准确，不能写错字。标题是第一视觉焦点，具有很强设计感。画面右上区域表现<地点>老城与<地域>风情建筑，包含<建筑细节清单>等具有<地域>特色的建筑细节，建筑紧凑排列，层层叠叠，形成密集的老街氛围。画面中部加入具有<地点>城市气息的街头元素，如老式招牌、凉茶铺标识、骑楼下店铺、木质招牌、<地域>窗花、复古路牌，以及具有地方感的交通与生活元素，增强街巷故事感。画面底部前景放大 2 到 3 个代表<地点>文化的巨型元素，例如<本地特产/文化元素清单>。物体比例夸张，可以像建筑一样大，从左右底角延伸进画面，与街区建筑形成超现实拼贴关系。整体色彩以暖黄、珊瑚橙、朱红、米白、青绿色为主，形成鲜明对比，避免整张画面被单一颜色覆盖。构图饱满但层次清晰，元素前后穿插，几乎没有无意义空白，但主标题必须清晰可读，地标建筑必须明确可辨。画面底部或角落以不抢眼的方式加入小号品牌文字「AIXZD ZHAPU PROJECT SERIES」，作为系列署名，排版精致克制，不影响主体视觉。最终输出为一张完整的历史街区商业插画海报，复古漫画感强，视觉张力足，极繁但有秩序，具有旅游海报与文创海报的高级设计感。

## 固定标注（所有输出必须带）
每次生成提示词，在提示词末尾（或合适位置）补充一句：**右上角粗体字标注：FAFO工作室**（2026-10-11 用户指定，pic 全部适用）。

## 交付规则（2026-10-12 用户定，pic 全部适用）
- 生成的图片**直接发当前频道**（MEDIA: 路径），不再只发邮箱
- 图片**先不清理**、保留在服务器（用户 2026-10-14 更新：暂不删，后续可能复查/复用）
- 长提示词/中间产物落 /tmp 的可清理，图片文件保留

## 出图（完整流程最后一步）
提示词生成后直接调默认文生图工具出图（RunningHub，见 runhub-image-gen 技能）：
```bash
python3 ~/tools/runhub/runhub_img.py t2i "$(cat prompt.txt)" --app 2098218128315609089 --out 输出.png
```
- **默认生图应用固定为 image2.5 sunburst (2098218128315609089)**：https://www.runninghub.cn/ai-detail/2098218128315609089（用户 2026-10-11 指定默认，~0.036元/张，不支持 ratio/res，输出约 3:4）
- 长中文提示词写入文件再 $(cat) 传入，避免 shell 转义；t2i 前把 markdown 符号清理为纯文本更稳
- 2026-10-11 实测：主题「宁德老登团」→ 复古波普拼贴 → 生成成功

## 经验
- 波普拼贴精髓：粗黑手绘轮廓+撞色色块+半色调网点+套印错位；左上超大 3D 挤压艺术字标题；底部 2-3 个巨型特产元素像建筑一样大
- 城市模板改造：主标题用主题名，建筑细节与巨型特产换成当地特色（例：宁德→闽东老墙/骑楼/畲族彩带+大黄鱼/白茶壶/光饼/线狮）
- 配色（暖黄/珊瑚橙/朱红/米白/青绿）与署名（AIXZD ZHAPU PROJECT SERIES）为固定模板，不随主题变
- pic 技能族：pic1-7 + picbp（复古波普）；触发时按模板区分
