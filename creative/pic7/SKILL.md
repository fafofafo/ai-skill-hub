# pic7 — 刊物风字体形变宣传海报提示词

把任意主题（歌名/概念/产品）改写为「超大字体对主体产生物理作用力形变」刊物风宣传海报提示词（image2.5 风格）。2026-10-11 由用户验证：主题「爱不释手」→ 环绕+挤压字体形变流程可用。

## 触发
- 用户给主题并要求「刊物风」「作用力」「字体形变」「宣传主视觉」风格
- 用户发来字段式模板（品牌/产品/核心文字/主体对象/动作...）+ 主题，要求「按原格式重新输出一份」
- 注意：输出**只要提示词内容**；模板允许人物/产品为主体，字体必须形变

## 模板字段（必须全部保留，格式固定）

制作一张冲击力十足的刊物风宣传海报，超大号字体对人物主体或产品产生的物理作用力做出形变反馈。
品牌：<品牌名>
产品 / 宣传活动：<产品或活动名称>
核心文字：<简短词汇>
主体对象：<人物 / 产品 / 两者兼有>
动作：<迈步 / 跳跃 / 拉扯 / 滑行 / 等等>
作用力类型：<挤压 / 推顶 / 环绕 / 滑动 / 其他>
作用力方向：<向下 / 向上 / 旋转 / 斜向 / 其他>
主色调：<颜色>
点缀色：<颜色>
画面比例：<9:16>
采用写实商业摄影风格、超大号字体、高对比色彩以及现代刊物版式设计。将核心文字做极大化处理，占据画面约 50–75% 的空间。字体需要直观体现所选作用力带来的形变效果，不能保持静止不变。示例效果：<按所选作用力展开>（挤压：受力接触点字母压缩/弯折/偏移；推顶：沿方向拉伸字体；环绕：粗大字母穿插主体前与后形成包裹；滑动：沿方向轴错位偏移）。字体形变必须贴合主体真实的动作与受力方向。字体要保持图形感且清晰可读，禁止做成柔和 3D、流体或者卡通样式的字母。构建清晰的前景–主体–背景层次互动，让人物或产品与字体产生真实的物理接触感。使用一种高视觉冲击力的主色，搭配黑白以及对比感点缀色。仅添加少量必要的宣传信息，例如品牌名、产品名、标语、参数、标签或简短刊物文案。人物与产品保持写实风格，比例、材质、光影、阴影、动态姿态均真实可信。最终成品为完整的宣传主视觉画面，作用力、主体、字体与构图形成统一联动的动态效果。

## 固定标注（所有输出必须带）
每次生成提示词，在提示词末尾（或合适位置）补充一句：**右上角粗体字标注：FAFO工作室**（2026-10-11 用户指定，pic1-7 全部适用）。

## 出图（完整流程最后一步）
提示词生成后直接调默认文生图工具出图（RunningHub，见 runhub-image-gen 技能）：
```bash
python3 ~/tools/runhub/runhub_img.py t2i "$(cat prompt.txt)" --app 2098218128315609089 --out 输出.png
```
- **默认生图应用固定为 image2.5 sunburst (2098218128315609089)**：https://www.runninghub.cn/ai-detail/2098218128315609089（用户 2026-10-11 指定默认，~0.036元/张，不支持 ratio/res，输出约 3:4）
- 长中文提示词写入文件再 $(cat) 传入，避免 shell 转义；t2i 前把 markdown 符号清理为纯文本更稳
- 2026-10-11 实测：主题「爱不释手」→ 环绕+挤压字体形变 → 生成成功

## 经验
- 字体形变精髓：核心文字占画面 50-75%，形变必须贴合主体动作与受力方向（例：捧握→手指收拢处字母挤压），禁止柔和 3D/流体/卡通字母
- 主题=歌名时：品牌可用 FAFO工作室，产品/活动写「<歌名>（歌曲宣传）」，核心文字用歌名，标语用主题英文句
- 作用力选择先想主题动作：捧/握→环绕+挤压；奔跑→推顶+拉伸；坠落→向下+压缩
- pic 技能族：pic1 通用/pic2 中轴夹景/pic3 字体穿透/pic4 国潮插画/pic5 纸艺立体/pic6 报纸拼贴/pic7 字体形变；触发时按模板区分
