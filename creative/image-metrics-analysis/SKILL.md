# image-metrics-analysis — 画面六维量化分析

用纯 PIL（无需 numpy/opencv/pip）对图片或视频抽帧输出六个客观指标，用于描述画风、对比调色差异、与视觉模型定性描述互相印证。

## 「六元素」标准定义（2026-10-24 用户定五元素，2026-10-27 加色调成六元素，硬性）
用户把以下六项统称 **六元素**（原五元素 + 色调）。**收到参考图建新技能时，只核对这六元素**，不要额外报高饱和像素、锐度 Laplacian 等其他指标（除非用户点名要）。

| # | 六元素 | 脚本字段 | 提示词里的对应约束方向 |
|---|---|---|---|
| 1 | **饱和度** | S 均值 % | 色彩浓艳/淡雅、高饱和撞色 or 低饱和克制 |
| 2 | **R-B** | R 均值 − B 均值 | 色温冷暖：正=暖偏红黄，负=冷偏蓝青 |
| 3 | **明度** | HSV-V 均值（灰度均值仅参考）| 画面亮暗：高调明亮 / 中调 / 暗调 |
| 4 | **柔度** | 柔度指数（<0.10 很柔 / <0.16 偏柔 / <0.24 中等 / ≥0.24 偏锐）| 过渡平滑柔焦 or 硬朗锐利 |
| 5 | **边缘** | 边缘密度（FIND_EDGES >20 / >40 占比）| 构图密度：极简大色块 or 密集细节 |
| 6 | **色调**（2026-10-27 新增）| 主色相（HSV 色相 12 桶，S>40 统计，如 青/青蓝/蓝/红/橙/黄/绿/紫）+ 占彩色 % | 主色相倾向（如「青蓝冷调主导」「暖橙调」「红蓝撞色」）|

**用法**：参考图 → 跑脚本取六元素 → 逐条翻译成提示词约束 → 建技能写六元素验收区间 → 出图后复测只比对这六项 → 文字另用 VL 逐字复核。脚本 `[7 色调]` 输出主色相桶+占比，配合 `[色温 R-B]` 判冷暖；色调与 R-B 相辅相成（R-B 看冷暖数值，色调看主色相）。

## 触发
- 用户要求「从饱和度、高饱和像素、锐度、边缘密度、明度、对比/柔度这几个维度分析」某图/某视频帧
- 需要客观量化两组画面的调色/清晰度差异（同曲不同版、不同 UP 主画风对比）
- 需要判断画面是「高饱和撞色」还是「柔和低对比」路线

## 脚本
技能自带：`scripts/img_metrics.py`（本技能目录内）；同时存在全局副本 `~/.hermes/scripts/img_metrics.py`。
另有 `scripts/pil_probe.py`：**VL 不可用时的兜底粗验**——输出中央主体区红/白色系像素占比（确认主体特征在）+ 左上标题/右上标注/底部署名区像素 std（std 大=有文字对比）。
另有 `scripts/hue_buckets.py`：**学色调/色相分布量化（2026-10-27 视频号学色调实测）**——按 30° 色相桶统计有色彩像素占比，回答「主色相到底是什么色、占多少」。R-B 只给冷暖方向（如 -68 冷青蓝），色相桶分布给出决定性细节（青 120-150° 占 62-72% + 青蓝 150-180° 占 13-26% = 青蓝系 85-95% 绝对主导 + 橙黄点缀 5-6%）；VL 不可用时它是色调定性的唯一量化通道，报「色调」时给 R-B + 色相桶两项。

## 六维口径（与 OpenCV 对齐）
| 维度 | 算法 |
|---|---|
| 饱和度 | HSV S 通道均值 + 标准差（PIL convert('HSV')）|
| 高饱和像素 | S≥60% 与 S≥80% 两档像素占比 |
| 锐度 | 4-邻域拉普拉斯卷积**方差**（等价 `cv2.Laplacian(gray,CV_64F).var()`）|
| 边缘密度 | FIND_EDGES 后 >20 / >40 像素占比；另给 Sobel gx/gy 梯度幅值 |
| 明度 | 灰度均值 + HSV-V 均值（两者差距大=高饱和画面）|
| 对比 / 柔度 | 灰度 std + P5-P95 动态范围；柔度 = BoxBlur(3) 高频残差 / 全局对比 |
| 附 | R/G/B 均值与色温 R-B |

柔度分级：**<0.10 很柔 / <0.16 偏柔 / <0.24 中等 / ≥0.24 偏锐**

## 踩坑（重要）
1. **PIL Kernel 会裁剪负数**：直接用 `scale=1, offset=128` 跑拉普拉斯，负值被截到 0，方差严重失真（实测真值 724 vs 裁剪值 162，差 4.5 倍）。**必须用 `scale=4.0` 缩放后算方差再 ×16 还原**。
2. **numpy/cv2 常不可用**：本机系统 python 无 numpy、无 pip；不要试图装，PIL 的 ImageFilter/ImageStat/ImageChops 完全够用。
3. **视频帧分辨率影响绝对值**：B 站未登录只给 480p/360p，锐度与边缘密度绝对值会显著低于原始 4K；跨视频对比要注明分辨率是否一致。
4. **统计口径不可混用（会导致“差 5 倍”的假结论）**：本技能脚本用「拉普拉斯**方差**」（如 724），而快速反解常用另一套「拉普拉斯**绝对值均值**」（如 3.79-21.69）+「S>0.6 单档占比」。两套数量级差约 100 倍，拿不同口径的数字直接比会误判锐度/边缘相差数倍。拿到历史数值先确认属于哪套口径，同一轮对比只用一套；写技能验收区间时标注口径。
5. **HSV V 不要写成标量**：`V = hsv[...,2].mean()/255` 得到的是单个浮点，后面 `(V<0.25).mean()` 恒为 False → 暗部/高光占比永远打印 0%（实测踩过，两个指标同时报 0 就是此 bug）。先保留数组 `Va = hsv[...,2]/255.0`，再分别 `Va.mean()` 与 `(Va<0.25).mean()`。
6. **五元素「明度」验收区间按 HSV-V（V 均值），不是灰度均值**（2026-10-26 白发魔女海报实测）：大面积冷色/月夜/深色背景会把灰度均值压到 50% 以下（实测灰度 47%），但 V 均值 62% 仍在 pic 家族 55-65% 区间内——判明度是否达标先看 V（`HSV-V 157/255≈62%`），灰度仅作高饱和诊断（灰低 V 高=高饱和画面）；按灰度判会误报「偏暗」去白跑一版。脚本输出的「灰度均值 120.0/255 (47.0%) HSV-V 157.3/255」两值里，验收看后者。

## 解读范例（实测：短剧红蓝调色特写 @2.7s）
```
S 均值 72.2% / S≥80% 占 42.6%   → 高饱和红蓝撞色调色
Laplacian 方差 724              → 中偏低，有柔焦/降噪
边缘 >40 仅 1.8%                → 极简构图，大色块
灰度 117 但 V 190              → 高饱和致 V 高灰低
柔度 0.035（很柔）              → 过渡平滑，非硬锐
R-B +62.8                      → 强暖红偏色
```
定性：**高饱和红蓝撞色 + 中低锐度 + 极柔过渡 + 大面积纯色背景的电影调色特写**——靠色彩张力取胜、不靠细节锐度。

## 反向推理成提示词技能（量化→提示词→复测 闭环）
用户要求「把这些指标反向推理成 picX 技能」时按此四步，不要只写风格形容词：
1. **指标→约束映射表**：每一维都写成具体的提示词句式（如 S≥80% 占 42.6% → 「整体高饱和浓艳、色彩占据画面大部分」；边缘>40 仅 1.8% → 「大面积纯色背景、不留杂乱细节」）。只挑关键三维（色彩/锐度/背景密度）设成「缺一即不像」的硬要素。
2. **建技能**：把映射表原样写进 SKILL.md，并留下**量化验收区间**（出图后应落在什么范围），否则未来会话无法判断是否跑偏。
3. **出图后必须复跑本脚本**：不能靠肉眼「看着挺像」下结论。**验收只核对五元素**（饱和度 / R-B / 明度 / 柔度 / 边缘）是否落区间——高饱和像素与锐度 Laplacian 仅作诊断参考，不作为对用户的验收口径。
4. **按偏离最大的单项改提示词重跑**：一次只针对 1-2 个偏离项改，改完再量，不要一次改所有。

## 反向推理后的典型偏差（实测）
- **情绪词会压黑画面**：主题/氛围含「幽魅/鬼气/夜/暗」时，即使提示词写了「明亮鲜艳」，出图 V 均值仍可能只有目标的一半（实测 86 vs 190）、S 掉 15 个百分点、R-B 从 +62.8 掉到 +20.7。**修法：加否定式锚点**「不是夜景不是暗调、中高调曝光、暗部不发黑、背景明亮而不是深黑」——只写正向词无效。
- **锐度反向上扬**：要求「柔焦」但出图 Laplacian 仍高于原帧（1086 vs 724），需补「磨皮柔化、皮肤纹理清淡但不糊」。
- **色温被背景拉低**：大量冷色背景会拉低整体 R-B，暖色主体面积不够时 R-B 上不去。
- **暗调/夜景题材本身会进一步压暗**：题材含「夜戏/暗调/昏暗/古装夜」时，即使写了「中低调」，出图 V 会掉到目标的一半以下（实测 41-49 vs 118）。「中低调」会被模型理解成更暗——修法：改写成「画面曝光充足、主体明亮清晰，暗部为深色而非死黑，人物面部与袍服细节完整可辨」。
- **局部暖光源会反翻整体色温**：原图偏冷（R-B −19.9）时，提示词里「火盆/烛火/暖光」描述一强，整体色温会被翻到 +10.7。修法：暖光限定「只在局部形成一道边缘光，不扩散全身；整体主色调仍是冷色、冷色占比最大」——暖光源必须显式限域，否则默认铺满。
- **视角/镜头几何类指令弱执行**：严格 90 度纯侧面、14mm 超广角畸变这类视角几何，image2.5 执行偏弱（两版都只给约 75 度侧转）。修法：物理化+否定式描述（「鼻梁完全朝左与画面平行，右眼右颊右耳被完全遮挡绝不出现」），仍不行则接受近似并如实告知用户，不要为单一项无限重跑。

## 修正是双向的：必须用「中值措辞」，否则过冲
单方向加强必过冲——实测四版迭代（同一主题、同一原帧指标）：

| 版本 | 关键措辞变化 | 结果 | 偏差 |
|---|---|---|---|
| v1 | 基础模板（含「明亮鲜艳」正向词）| V 86 / S 57% / R-B +20.7 | 情绪词压黑 |
| v2 | + 否定式锚点（「不是夜景不是暗调」）| V 167 / S 71.7% / Laplacian 716 | 三项命中，但 R-B −13.8 **偏蓝** |
| v3 | + 「红色绝对主导、占六成以上面积」+「饱和到溢出」| S **85.5%** / R-B **+95.8** / V 反降到 133 | **矫枉过正过冲** |
| v4 | 「红蓝接近对半、红色略多」+「高饱和鲜明但不过曝」| S 65.8% / R-B +35.0 / 柔度最佳 | 最平衡 |

**规则**：
- 修正只用**中值表述**——「接近对半、略多于」「鲜明但不过曝」「中等偏低」，不写「绝对主导/占六成/饱和到溢出」。带「绝对/极/溢」的措辞会把指标推过目标 30% 以上。
- **一次只调 1-2 项**，调完立刻复测；偏差会在方向上来回摆（偏暗→偏蓝→偏红过冲→平衡），2-3 版内用中值收敛即停。
- **亮度 V 有模型上限**：四版 V 落在 86-167，未达目标 190；追求极致亮度只能后期调色，不要为 V 反复重跑。
- **验收要排除文字贡献的边缘**：海报含主标题/署名文字时边缘密度必然高于无字原帧（实测 6-7% vs 1.8%）；纯背景部分达标即算通过，别把文字边缘当成画风跑偏。
- **⚠️ 比较两版指标前先确认版式结构一致，否则会把版式差异误判成画风跑偏**（实测同一鲜艳配方、同一主题、同一模型）：单层主体版饱和 31.4% / R-B +50；改成分层骨架（右上主体+中部元素+底部 2-3 个巨型纯色构件）后饱和飙到 **51.8%**、R-B **+91.9**、锐度反降到 559。机制＝底部巨型纯色块面积大、色相统一，直接抬高平均饱和与色温，同时大色块降低高频细节。**结论：饱和度/色温超标时先看画面有没有大面积纯色块（尤其底部巨型元素），有则按版式效应处理——给该版式单独定区间或加「色块总面积控制在 50% 以内、保留 30% 以上结构裸露面积」，不要去改配色措辞。**

## 同一配方跨主题验证：先区分「技法失控」与「主题固有颜色」（实测）
同一技能、同一措辞配方、连出 3 个主题，指标会系统性分档——**判偏离前先看主题自带什么颜色**：

| 主题 | 发色/主色 | S均值 | Laplacian | 边缘>40 | 柔度 | R-B | 达标 |
|---|---|---|---|---|---|---|---|
| 深色短发主题 | 墨黑 | 76.5% | 661 | 5.3% | 0.058 | +25.9 | 5/6 |
| 深色卷发主题 | 墨黑 | 71.4% | 755 | 6.4% | 0.067 | +40.5 | **6/6** |
| 白发主题 | **雪白** | 44.3% | 1499 | 12.3% | 0.102 | +9.7 | **2/6** |

**机制**：白发/浅发色/浅色服饰在大面积上形成①低饱和浅色块 → 拉低 S；②细密高对比发丝 → Laplacian 与边缘密度翻倍、柔度掉出「很柔」；③中性色稀释暖色 → R-B 下降一个档。三项同时发生。

**同一深色发色下，发型长度也会分档**（墨黑短发 vs 墨黑长直发，同技能同配方）：短发 Laplacian 661 / 柔度 0.058（5/6 达标），长直发 963 / 0.088（4/6，仅锐度与柔度越界）。发丝面积越大、边缘纹理越多，锐度与边缘密度越高、柔度越低。**选型优先短发/盘发；长发主题在提示词加「发丝柔化、发丝边缘融入背景」，验收时 Laplacian 放宽到 600-1100。**

**规则**：
- **判定**：同一配方在深色主题达标、浅色主题全项偏移 → 是**主题固有颜色**造成，不是提示词失效。此时**不要重跑调措辞**（调不回来，除非改变主题的固有颜色），直接采用深色版本作基准图，并如实告知用户该画风与浅色/白发主题不兼容。
- **选型**：高饱和撞色调色类画风（S 目标 >65%、强暖色偏色）优先选深色发色/深色主色主题；浅色主体主题应换低饱和或高调画风（如青橙冷调/奶油色调）。
- **验收区间要带主题前提**：给技能写量化验收区间时标明「适用于深色主体主题」；浅色主题单独给放宽区间（S 允许 −15pt、Laplacian 允许 ×1.5、边缘允许 +5pt）。
- 这一条与上文「锐度反向上扬」「色温被背景拉低」是同一族的偏差源——都先找画面构成原因，再改措辞。

## 经验
- **2026-10-24 用户定义「五元素」**：饱和度 / R-B / 明度 / 柔度 / 边缘。以后给参考图建新技能，**只核对这五项**，回报也只报五项（附实测值与目标区间），不要堆其余指标。锐度/高饱和像素留作内部诊断。
- **验证过的配方要原样下沉到同族技能**：某个画风在 4 版迭代里收敛出可用措辞后（如「明亮中高调、不是夜景不是暗调」+「红蓝接近对半、红色略多」+「高饱和但不过曝」），把这段措辞整段抄进同画的 picbpnew 骨架版/美女版/MV 版技能，而不是让它们各自再迭代——实测同配方换骨架后一次即命中 5/6 项验收区间。
- 指标要与视觉模型描述**互相印证**：先用 Qwen3-VL 描述内容/画风/光影，再用六维数据量化，两者结合才能给准确画风画像。视觉模型对「锐度/柔硬」的主观判断常与拉普拉斯+柔度不符（实测它说「锐利硬朗无柔化」而柔度 0.058 属很柔档）——**量化优先，主观描述只用于内容确认**。
- 单独看某个指标易误判：例如「拉普拉斯高」可能是噪点多而非清晰；要结合柔度与边缘密度一起看
- 同一视频多帧取样（如每 30s 一帧）可看出画风是否统一、有无风格跳变
