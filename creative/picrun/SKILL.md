## 模板结构（用户提供的固定模板，中文，4:5 竖版）

### 一、统一母版提示词
生成一张 4:5 竖版高端运动品牌商业海报，主题为 SKECHERS GO RUN RAZOR「KEEP GOING」系列视觉。整体风格参考国际运动品牌 Campaign、精品旅行杂志与高端商业摄影，画面真实、克制、有电影感，强调持续前进、日常坚持、自由奔跑的情绪。

**场景设定**：画面发生在【可修改：场景】。例如：【城市清晨街道 / 海岸悬崖公路 / 雨夜城市 / 山顶日出 / 现代跨海大桥 / 国际机场建筑群】环境中加入【可修改：核心环境元素】，形成明显的空间纵深和旅行感。例如：【玻璃建筑、城市道路、日出】【海面、悬崖、弯曲公路】【湿润路面、灯光倒影、细雨】【群山、晨雾、日出光线】【桥梁拉索、水面、远处城市】【航站楼、玻璃幕墙、远处飞机】。场景整体保持干净、克制，不要出现拥挤人群和杂乱背景。

**人物与产品**：画面中出现一名正在奔跑的年轻运动员。采用背后约45°的后侧视角，人物全身入镜，跑姿自然真实，身材精干有训练感，但不要过度肌肉化。人物穿着简洁的 Skechers 运动装备：白色或冷灰色技术背心、轻量跑步短裤、白色运动袜，以及 Skechers GO RUN Razor 跑鞋。跑鞋需要自然融入跑步动作，清楚展示鞋侧轮廓与鞋底结构。重点保证：人体比例自然、双腿和双脚结构正确、跑鞋不变形、鞋底与地面关系真实、衣服有自然褶皱和风吹效果、不要把鞋夸张放大、不要出现漂浮产品。

**核心视觉排版**：在画面中加入一组巨大、超窄、纵向延伸的英文主视觉字体：【可修改：核心大字】例如：【MOTION / DISTANCE / AGAIN / RISE / NEXT / ANYWHERE】。主文字占据画面大部分高度，形成强烈视觉锤。人物与字体产生前后遮挡关系，部分文字可以被人物、建筑、道路或环境元素遮住，让字体像画面中的建筑结构一样参与构图。整体采用：非对称构图、大面积留白、巨型字体、人物与文字穿插、强烈纵向视觉节奏、高级杂志式排版。

**文案系统**：左上角加入：AI SPORT / GO RUN RAZOR / SPRING SUMMER 2026；主视觉大字：【可修改：核心大字】；辅助标题：KEEP GOING；辅助文案：【可修改：一句短文案】例如：Every morning is another chance to move forward. 或：The road gets longer. So do you. 或：Rain changes the road. Not the reason. 或：Different city. Same reason to run.；按钮文案：DISCOVER NOW →；右侧竖排小字：【可修改：系列信息】例如：GO RUN SS26 / RUN REPEAT / SS26 / GO RUN GLOBAL / SS26；底部：Daily AI Research Circle。控制文字数量，保证标题清晰，不要堆积过多小字。

**色彩与光影**：整体采用冷色高级运动视觉：深海蓝、钢蓝、午夜蓝、冰白、钛银、浅青色。再根据场景加入少量【可修改：点缀色】。例如：城市晨跑 → 淡金色日出；海岸公路 → 青蓝色海面；雨夜城市 → 冷青色反光；山顶日出 → 淡金与浅橙；跨海大桥 → 银蓝与暖金；机场 → 香槟金晨光。光影采用电影级商业摄影效果：冷色环境光、人物边缘轮廓光、自然长阴影、真实环境反射。避免过度霓虹、过曝、高饱和和廉价科技感。摄影视角采用：40–50mm 商业摄影镜头效果、全身竖版构图、略微低机位、后侧约45°视角、冻结自然跑步瞬间、背景保留明显空间纵深、跑鞋保持清晰细节、人物与环境比例自然、画面需要兼顾人物、产品、环境和字体，不要把人物塞满整个画面。

**整体效果**：最终效果像一套真实发布的国际运动品牌 Campaign：高端商业摄影、精品旅行广告、运动生活方式和现代平面设计结合。画面真实、有呼吸感、有故事性。不要图库广告感，不要普通健身房宣传海报，不要廉价 AI 光效，不要过度英雄化人物，不要复杂装饰。

### 二、最常修改的 5 个变量（制作系列图时主要改这些）
【场景】城市晨跑 / 海岸 / 雨夜 / 山顶 / 大桥 / 机场
【核心大字】MOTION / DISTANCE / AGAIN / RISE / NEXT / ANYWHERE
【辅助文案】根据每张图的主题换一句短句
【环境元素】建筑、海面、雨水、山脉、桥梁、飞机等
【点缀色】日出金、冷青、银灰、浅橙等
