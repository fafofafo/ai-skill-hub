# pic4 — 国潮商业插画海报提示词

把任意主题（歌名/概念/城市夜宵文化）改写为「国潮商业插画」海报提示词（image2.5 风格）。2026-10-11 由用户验证：主题「睫毛上的心跳」→ 夏夜夜市心动场景流程可用。

## 触发
- 用户给主题并要求「国潮」「商业插画」「招贴感」风格
- 用户发来字段式模板（【主题定位】/【核心场景】...）+ 主题，要求「按原格式重新输出一份」
- 注意：输出**只要提示词内容**；模板允许人物（中景人物是标配）

## 模板字段（必须全部保留，格式固定）

【主题定位】生成一张以<主题>为主题的国潮商业插画海报。
【核心场景】地点位于<场景>。桌上摆放<食物1>、<食物2>、<食物3>，加入<细节>；可加<主题相关的手部/动作细节>。
【城市元素】背景融入<城市元素清单>。
【构图】3:4竖版海报。前景是<前景内容>，中景是<人物动作>，后景是<后景内容>。使用适度近大远小透视，让食物和人物动作更突出。
【国潮风格】现代国潮商业插画风。融合手绘线稿、平涂插画、复古印刷颗粒和传统招贴感。人物穿现代服装，画面年轻、有街头感和烟火气。
【色彩】主色使用<主色>。辅助色使用<辅助色1><辅助色2>。标题重点使用芥末黄色，整体鲜明，但保留复古印刷质感。
【文字系统】主标题：「<主文案>」副标题：「<城市/时节> · <副文案>」主标题使用醒目的国潮艺术字，可以稍微倾斜、错位，增强画面张力。
【质量】高清晰度，精致国潮商业插画，人物五官自然，手部准确，食物细节清楚，排版完整，文字准确，无乱码，无多余肢体。

## 出图（完整流程最后一步）
提示词生成后直接调默认文生图工具出图（RunningHub，见 runhub-image-gen 技能）：
```bash
python3 ~/tools/runhub/runhub_img.py t2i "$(cat prompt.txt)" --app 2098218128315609089 --out 输出.png
```
- **默认生图应用固定为 image2.5 sunburst (2098218128315609089)**：https://www.runninghub.cn/ai-detail/2098218128315609089（用户 2026-10-11 指定默认，~0.036元/张，不支持 ratio/res，输出约 3:4）
- 长中文提示词写入文件再 $(cat) 传入，避免 shell 转义；t2i 前把 markdown 符号清理为纯文本更稳
- 2026-10-11 实测：主题「睫毛上的心跳」→ 夏夜夜市心动国潮插画 → 生成成功

## 固定标注（所有输出必须带）
每次生成提示词，在提示词末尾（或合适位置）补充一句：**右上角粗体字标注：FAFO工作室**（2026-10-11 用户指定，pic1-5 全部适用）。

## 经验
- 主题=歌名时：把歌的情感内核落成「夜市/街头的一个心动瞬间」（例：靠近的男女、悬停杯沿的手、睫毛轻颤），保留国潮烟火气框架
- 芥末黄标题 + 暖橙红主色 + 靛蓝辅助 = 国潮经典配色三角；3:4 竖版是模板固定格式
- pic1=通用海报（禁人物）；pic2=中轴夹景（人物动作夹景）；pic3=字体穿透摄影（人物入画）；pic4=国潮商业插画（中景人物标配）；触发时按模板区分
