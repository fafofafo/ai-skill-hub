## 🧠 AI 技能方法论

技能之外，这套库沉淀了三条实战方法论：

### 1. 三步法文案
任何内容创作任务，先问三个问题：**给谁看？要什么反应？凭什么信？**——然后按"钩子→价值→行动"三步组织输出。

### 2. 学习 RLT 闭环
**Read（读）→ Link（联）→ Teach（教）**：读后必须链接到已有知识，再输出教学（笔记/教程/技能），才算真正学会。

### 3. 技能即资产
把重复劳动写成技能 = 一次投入、反复复用、持续进化。每个技能都是**可积累、可复利**的资产。
