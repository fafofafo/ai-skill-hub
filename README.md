# 🤖 AI 技能库（ai-skill-hub）

> 中文 AI 实战技能库：**368 个可复用技能**，全部脱敏开源。
> 每个技能 = 一个可加载的 SKILL.md（含触发条件、完整流程、踩坑笔记）。

## 这是什么

一套**经过实战验证的中文 AI 技能集合**，覆盖：AI 创作（海报/MV/视频）、效率工具、研究调研、内容变现等场景。每个技能都包含：
- **触发条件**：什么时候该用
- **完整流程**：一步步怎么做
- **踩坑笔记**：实测中遇到的真问题与解法

## 快速开始

技能目录结构：
```
<分类>/<技能名>/SKILL.md          # 技能主文档
<分类>/<技能名>/scripts/          # 配套脚本（可选）
<分类>/<技能名>/references/       # 参考资料（可选）
```

每个 SKILL.md 都遵循同一结构：**frontmatter（name/description）→ 使用场景 → 完整流程 → 踩坑笔记**。

## AI 技能方法论

技能之外，这套库沉淀了三条实战方法论：

### 1. 三步法文案
任何内容创作任务，先问三个问题：**给谁看？要什么反应？凭什么信？**——然后按"钩子→价值→行动"三步组织输出。

### 2. 学习 RLT 闭环
**Read（读）→ Link（联）→ Teach（教）**：读后必须链接到已有知识，再输出教学（笔记/教程/技能），才算真正学会。

### 3. 技能即资产
把重复劳动写成技能 = 一次投入、反复复用、持续进化。每个技能都是**可积累、可复利**的资产。
