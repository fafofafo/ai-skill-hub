## 🧠 Methodology

Three practical methodologies distilled from this library:

1. **Three-step copywriting**: Ask *who is it for? what reaction? why trust?* then structure as *hook → value → action*.
2. **RLT learning loop**: *Read → Link → Teach*. Link new knowledge to existing, then teach it out — that's real learning.
3. **Skills as assets**: turning repetitive work into skills = invest once, reuse, compound.
