# 营销思维框架：高汀 + 奥格威（2026-09-23 固化）

## 赛斯·高汀（Seth Godin）——差异化与注意力
1. **紫牛（Purple Cow）**：平凡=隐形；产品/内容必须"非凡到值得被谈论"，否则不存在。问：这个会被主动传播吗？
2. **许可营销（Permission Marketing）**：先获得注意许可再营销；未经许可的打扰=垃圾。内容先给价值换许可，再推销。
3. **部落（Tribes）**：找到/领导一个小而认同的群体，比向大众喊话有效。
4. **最小可行受众（MVA）**：不要"所有人都能买"，找**最小一批愿意付费且会传播的人**——为他们做极致。
5. **拒绝平庸承诺**："对所有人有点用"=对所有人没用。

## 大卫·奥格威（David Ogilvy）——直接销售文案
1. **标题定生死**：80% 的人只读标题——标题必须给具体好处/新闻性，别玩文字游戏。
2. **承诺（Promise）**：广告必须承诺一个具体利益，而不是形容词堆砌（"更好"是废话）。
3. **具体 > 抽象**：用数字、事实、案例（"省 3 小时/天" > "高效"）。
4. **消费者不是傻子**：她是你的妻子/朋友——写人话，别自嗨。
5. **可验证的直接回应**：给明确行动（点击/咨询/试看），让效果可追踪。
6. **长文案没关系，啰嗦不行**：事实充分的长文好于空洞短文，但每句要有信息。

## 应用场景映射（配合我们的线）
| 场景 | 用谁 | 怎么用 |
|---|---|---|
| 卖 Skill 产品页/种草 | 高汀 MVA + 紫牛 | 差异化卖点 + 最小受众定位 |
| 小红书标题/封面 | 奥格威标题定生死 | 具体好处 + 数字 + 直给 |
| 接单报价/提案 | 奥格威承诺 + 具体 | demo-first + 里程碑 + 数字 |
| 客户方案书 | 高汀许可营销 | 先给价值（免费 demo）再谈单 |
| 内容选题 | 高汀部落 | 服务一个小而认同的群体 |

## 检查清单（写任何营销内容前过一遍）
- [ ] 紫牛：这会被主动传播吗？
- [ ] MVA：为谁做到极致？（不是所有人）
- [ ] 标题：给具体好处了吗？（不是形容词）
- [ ] 承诺：能说出一个具体利益吗？
- [ ] 数字：有事实/案例支撑吗？
- [ ] 人话：像对朋友说话吗？
