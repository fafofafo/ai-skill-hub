# marketingskills 核心工作流（蒸馏自 coreyhaines31/marketingskills，54k stars，MIT）

> 2026-10-13 蒸馏。原则类见主 SKILL.md（高汀/奥格威）；这里是可执行工作流。
> 触发场景：写营销内容/改落地页/定价前，先按对应流程走一遍。

## 1. product-marketing：先立上下文，再写任何营销内容
任何营销任务前，先确认是否有产品营销上下文（定位/ICP/卖点/渠道语气）：
- 没有 → 先问/先查：这是什么产品？给谁（ICP）？凭什么买（差异化卖点）？各渠道语气？
- 有 → 所有文案引用同一上下文，保证多渠道核心卖点不跑偏
- 输出：一段产品定位文档（后续所有营销技能共用）

## 2. CRO：落地页/产品页按影响度顺序诊断
1. **价值主张清晰度**（影响最大）：5秒内能懂这是什么+为什么值得关心？写顾客语言，不写公司黑话；特征罗列→利益导向
2. **标题有效性**：传达核心价值？够具体？与流量来源信息匹配？
   - 强标题模式："获得[想要的成果]而不用[痛点]"；带数字/时间；社会证明"10,000+团队..."
3. **信任与社会证明**：客户评价/logo/数据可验证
4. **行动门槛**：按钮文案具体（"立即开始" > "提交"）、表单字段最小化
5. **测量**：明确主转化目标（注册/试用/购买/咨询），改一处测一处

## 3. pricing：三大定价轴 + 价值定价
- **打包**：每档含什么（功能/额度/支持等级），档间差异清晰
- **计价单位**：按人 / 按用量 / 固定费，价格随交付价值增长
- **价格点**：实际金额；参考竞品 + 客户愿意付多少（Van Westendorp）
- 原则：按**交付价值**定价，不按成本；报价时先讲价值再讲价

## 4. 其他常用弹药（速记）
- 竞品分析：带目的拆（对方软肋→撕缺口→对外话术），不是抄官网
- 冷邮件：先价值后推销、具体可行动、追踪打开
- 文案渠道适配：同一产品，小红书/朋友圈/客户提案语气不同但核心卖点一致
