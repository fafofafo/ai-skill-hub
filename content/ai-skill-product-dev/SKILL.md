# AI Skill 产品化（把能力蒸馏成可售卖的数字产品）

## When to Use
- 用户想把 AI 实战经验/教程/方法论打包成 Skill 售卖（小红书 / Gumroad / Etsy）
- 用户想评估"卖 AI Skill"这条变现方向（或收到相关视频/文章想判断）
- 用户已有产品需求：做新 Skill 样板、定价、上架、引流

## 市场认知（调研 2026-09，有数据）
- **Gumroad 大数据**：AI 工具品类 ~29% 成功率，赢家平均 ~$18k；营销类 31%，~$21.5k
- **真实案例**：卖 ChatGPT prompts 捆绑 6 个月 ~$14k（Medium 引流占 50% 成交）
- **小红书**：高客单价可达 40万+（核心是卖"可落地执行方案"，不是信息量）
- **腾讯 SkillPay**（2026-07）：官方验证"技能是新商品"（SkillHub 7.8 万技能/3000 万下载）——但不追腾讯生态（门槛高）
- **现实**：只有 ~30% 产品跑赢；**核心门槛是营销**（Medium/Reddit/SEO/内容账号引流），不是"放上去就卖"；通常要 3-6 个月经营

## 版权边界（红线，必须守住）
- **原创衍生 = 合法**：看别人的视频/文章学"方法/思路"（思想不受版权保护），用**自己的话/自己的演示/自己的案例**重写成 Skill → 这是原创
- **直接搬运/复制他人文案内容 = 侵权**（跨国也有追责风险；"国内国外版权忽略"是危险乐观）
- 绝不"搬运国内视频改壳卖"
- 红线判断：Skill 里是"你提炼的方法"（OK）还是"逐字复制的内容"（侵权）

## 蒸馏方法论：五层蒸馏法（2026-09-12 并入，源自 nuwa-skill 32k★）

做 Skill 时不止蒸流程，可蒸「人/思维」维度。蒸馏任何主题/人物/经验按五层提取：
| 层次 | 提取什么 |
|---|---|
| 1 怎么说话 | 表达 DNA——语气/节奏/用词偏好 |
| 2 怎么想 | 心智模型、认知框架 |
| 3 怎么判断 | 决策启发式、价值倾向 |
| 4 怎么应对不确定 | 面对模糊/风险时的行为模式 |
| 5 认知操作系统 | 让同题不同人做不同判断的核心差异 |

- 工作习惯靠流程文档传；**认知框架才是高溢价**（卖"可落地执行方案"已不够，卖"思维操作系统"更高价值）
- 蒸馏人物时：自动调研→提炼→验证全流程；先造「人物文风档案」（表达 DNA 层）再写内容
- 与「人味三步法」汇合：写作/内容 Skill 先建目标人物文风档案

## 标准生产流程：idea-to-deploy 七步门禁（2026-09-21 并入，源自 rlaope/oh-my-hermes omh-idea-to-deploy ★2848）

从想法到上线的端到端流程，每步有显式门禁，**门禁不过不放行**。核心原则：证据边界——任何产出只报告"已经发生/尚未发生"的诚实状态，不靠叙述声称完成；每步命名最小下一步验证/交接。

| 步骤 | 做什么 | 门禁（不过不放行） |
|---|---|---|
| 1️⃣ **Shaping 塑造** | 想法 → 目标用户/痛点/差异化；用五层蒸馏法选定主题和认知框架 | 明确"卖给谁/解决什么/凭什么是我" |
| 2️⃣ **Decision Gate 决策门禁** | 值得做？市场验证（Gumroad/小红书竞品与需求）+ 版权红线检查 + 成本收益（token/工时 vs 售价）| 有需求证据 + 无侵权风险 + 可盈利 |
| 3️⃣ **Plan Acceptance 计划接受** | 产出物清单（SKILL.md/模板/真实案例/中英版/README）+ 里程碑 + 验收标准 | 清单齐、验收标准可测 |
| 4️⃣ **Build 生产** | 按产品结构产出，含真实演示/可运行案例；打包 ZIP | 产出物完整 |
| 5️⃣ **Verification Gate 验证门禁** | **执行锚定自检**（意图→产出对照）+ **smoke_test**（真实验证：能运行、演示可复现、不靠嘴说）+ 证据边界标注（哪些验证了/哪些没验证）| 验证通过或有明确"未实测"标注，才可进发布 |
| 6️⃣ **Release 发布** | 定价（低价试水 39-99 元 → 有成交提价）+ 上架（小红书/Gumroad）+ 引流启动（Medium/Reddit/内容账号）| 产品页卖点清、引流路径已启动 |
| 7️⃣ **Monitor 监控** | 销售/反馈数据 → 迭代（改价/改文案/扩内容/新主题）| 有数据回流机制 |

**适用范围**：新 Skill 产品化、评估想法、迭代已有产品。**不适用**：单任务/简单问答直接处理，别开产品循环。

## 产品结构（已验证样板 ~/skill-product/）
```
SKILL.md（frontmatter + 核心方法论：适用人群/原理/步骤/模板/真实案例/清单/避坑）
+ 模板（如 Agent 角色卡）+ 落地清单 + 真实案例
+ 中英双版（小红书用中文 / Gumroad 用英文）
+ README（一句话卖点 + 含什么 + 适合谁 + 为什么值）
```
- 打包 ZIP：用 python zipfile（`zip` 命令常未安装）：
  `python3 -c "import zipfile,os; z=zipfile.ZipFile('x.zip','w',zipfile.ZIP_DEFLATED); [z.write(os.path.join(r,f)) for r,_,fs in os.walk('dir') for f in fs]"`

## 上架路径
- **小红书**：标题抓痛点（"我用 AI 团队替我干活，每天省 3 小时"）+ 正文展示真实效果 + 私信/评论引流；先低价试水（39-99 元），有成交再提价
- **Gumroad**：$19-29 对标市场；产品页写清卖点；引流 = Medium 文章 + Reddit 垂直社区（r/automation、r/AI_Agents、r/productivity）+ 内容账号
- 引流是成败关键（参考：Prompt Advance $14k 案例 50% 成交来自 Medium）

## Pitfalls
- **差异化 = 能做的 vs 搬运的**：用户能做出"真能用"的 Skill（有演示、能运行），比干巴巴文字包值钱；卖"可落地执行方案"才能高溢价
- 别为 SkillPay / Web4 / "AI 自主赚钱"类卖课概念付费——多属割韭菜
- 别用刷量工具（SuperAICrew 类自动点赞评论）= 平台明令禁止，封号毁账号
- 定价算进平台佣金（Gumroad/Etsy 抽成）
