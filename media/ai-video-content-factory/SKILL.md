# AI 视频内容工厂（content factory）

## 分工（用户明确要求，勿回归）
- **智能体负责一切生产**：选题、写完整脚本、标题/封面/简介/标签、内容库管理与进度看板、数据迭代分析。主动产出并直接写进内容库文件交付，不等用户催。
- **用户只负责**：平台账号注册、必要的 API 申请、录制（设备录屏+配音）、发布、回填播放数据。
- 不要替用户做"注册/发布"这类需要其账号的动作；其余生产类动作全部自己完成。

## 内容库与流水线（本机 ~/ai-video-content/）
- `选题库.tsv`：看板，列=选题编号|标题|定位/一句话|优先级|脚本|录制|发布（`✅`/`⬜`）。
- `NN_脚本_标题.md`：每条完整脚本 = 3 个标题备选(A/B测试) + 封面大字文案 + 简介 + 带时间轴口播稿（`🖥`=屏幕演示点）+ 演示步骤清单 + 标签。
- `gen_script.py`：`--status` 看进度；`--num NN` 为指定选题生成骨架（我随后填充正文）。
- `_发布检查清单.md`：每条发布前逐项核对（含 AIGC 打标、冷启动回评、发布后 72h 数据回填）。
- `README.md`：制作流程 + 数据复盘清单。

## 关键打法（差异化）
- **脚本必须基于用户机器上真实运行的系统**（Hermes 网关、agent-memory、cron 定时任务、腾讯云服务器）——录屏即得、别人抄不走。每个演示步骤写"可对照的真实命令/界面"。
- 每条脚本含 A/B 标题、封面文案、时间轴分段，把录制剪辑成本降到最低。
- 数据回流：发布后把播放/完播/评论填回看板，由智能体分析迭代选题（哪个爆做哪类）。
- 进度自动沉淀进 agent-memory（project 类），跨会话 `agent-memory recall "内容创作"` 恢复上下文。
- 优先级：🔥=第一批先做（易爆/现成系统可演示）、⭐=第2-3月、○=进阶。

## 陷阱
- **用户贴外部内容（工具/赚钱方法论）时，先验证再采用**：用 Tavily 搜索核实、探测可疑域名（如 `gemini3-pro.com` 冒充 Google 官方——模型真实存在≠那个工具可信）。识别营销话术：无来源的精确数字、紧迫感窗口期（"2024-2027 最后窗口"）、"免费+上传本地文件"=收集数据。别把粘贴内容的结论当事实。
- 演示口播里的"截图/数据"要用真实命令输出，不编造；涉及密钥/隐私先脱敏再写进脚本。
- 不要一次在一个会话里手写全部 20 条脚本（token 爆炸）——用生成器骨架+分批填充，或先做前 3-6 条验证数据再继续。
