# 触发边界 + 外部内容验证（2026-08-25 用户纠正后沉淀）

## 触发边界：不要主动做视频（用户明确纠正，最高优先级）
- 用户分享外部内容（AI 工具 / 技术文 / 赚钱方法论）时，**默认只做"验证 + 讨论"**，不要主动提议"要不要做成视频 / 我帮你做条推荐视频"。
- **做视频必须用户明确指示**。用户原话："先不做视频，后续也不要马上就做视频"。
- 反例（本次会话被纠正）：用户贴 ThetaWave → 我 clarify 问"要不要做视频"；用户贴 BibiGPT → 我直接做了条视频。用户随后喊停："先不做视频，后续也不要马上就做视频"。
- 正确路径：贴内容 → 验证真伪 → 讨论价值/风险 → 等用户明确指示是否要产出（视频/存档/深入评测）→ 才动手。

## 验证外部 AI 工具/技术文案的可靠套路（本次会话验证 4 例）
1. **先查证再下结论**：Tavily 搜索 + GitHub API（api.github.com 快）。GitHub API 给真实星标/仓库/许可证，别信文案里的星标数。
   - 实例：文案说 MoneyPrinterTurbo "18.6k 星"，GitHub API 实测 **116k**——文案数字低 6 倍。
2. **模型/工具名先对官方命名**：`gemini3-pro.com` 冒充 Google 官方（真实模型 Gemini 3 存在 ≠ 那个工具可信）。官方域名是 gemini.google.com / thetawave.ai 这类，`<名>3-pro.com` 这类山寨域名要抓取验证。
3. **找底层证据**：论文项目 → 抓 arXiv 摘要核对（FreeToken = arXiv 2608.16157，753B/35B/8GB 全对上 → 核心真实；但"四倍于 Ollama""39.3 tokens/s"摘要里没有 → 宣传加料）。成熟工具 → 官网 feature 页核对。
4. **用物理常识换算戳穿离谱数字**（营销文高频造假点）：
   - LLM 生成速度：现实几十 token/s。"50 秒生成 40 万字" ≈ 60 万 token → 现实要 1.5~8 小时，快 100 倍 = 编造。
   - TTS 语速：约 1 分钟 300~500 字。"1 分 12 秒完成百万字配音" = 快 2500 倍，物理不可能。
   - "提速万倍 / 秒生成百万字 / 零成本印钞机" = 营销口号，不是数据。
5. **区分"论文证实事实" vs "官方宣传口径"**：做内容时如实标注，别把宣传当实测复现。
